# WordPress Phase 3 Harness 执行合同 V2

## 输入

Job Manifest 必须包含：

- `schema_version = 2.0`
- `project_id`
- `component_id`
- `run_id`
- `phase = PHASE3`
- `source`
- `environment`
- `tests`

`source.mode` 只允许：

- `none`：仅验证环境；
- `local_directory`：验证 Runner 临时目录中的目标源码与 Exact Git SHA。

Harness 不负责长期保存或跨仓运输源码。Public/Private Checkout 由当次临时 Workflow 根据数据分类完成。

## 环境

```text
WordPress 7.0.2
PHP 8.4
Apache
MariaDB 11.8.8
InnoDB
utf8mb4
```

所有容器、Volume、端口和 Evidence 都必须绑定唯一 `RUN_ID`，任务退出时必须执行 Cleanup。

## 输出

- `environment.json`
- `checks.json`
- `result.json`
- `logs/compose.log`

机器状态只允许：`PASS / FAIL / BLOCKED_ENV / BLOCKED_EXTERNAL / CANCELLED`。

本 Harness 的 PASS 只证明环境基线真实运行。项目功能、Release、Production 与在线状态必须由各自独立 Gate 证明。
